# Screens and UX

1 Dashboard: animal count, recent checkups, upcoming/overdue tasks, offline/local-only status, last backup warning.
2 Animals: search ear tag/name, species/status/group filters, add button, CSV import.
3 Animal profile: header, identification, timeline, vaccination history, treatments, tasks, archive action.
4 New animal: simple mobile-first form; required ear tag/species/sex; validation.
5 New veterinary event: select animal(s), type, date, vet, details; explicit save confirmation for batch.
6 Tasks: upcoming, overdue, done; create/edit/complete.
7 Data safety: export, import preview, restore, instructions, last backup date.
8 Settings: Albanian/English, farm display name, local-only explanation.

Visual direction: cream background, deep green #164B36, restrained gold accent; readable large touch targets; no mandatory internet assets or external font fetch.
